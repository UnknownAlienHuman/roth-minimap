# Roth Minimap

Lightweight minimap addon for WoW Retail (12.0+).

Goals:
- Square minimap (size/scale/options).
- Diablo skin (border + animated fire overlay).
- Button bag (collect buttons, keep minimap clean).

## Settings

Game Menu → Options → AddOns → Roth Minimap

## Slash commands

- `/rm` — open settings.
- `/rmb` — toggle bag (pins open/closed).
- `/rmb scan` — rescan minimap buttons.
- `/rmb reset` — restore moved buttons to original parents/positions.

## Notes

- Button rescans and re-parenting are deferred while you are in combat.
- Ping sound is optional and uses a soft UI sound (not a raid warning).
